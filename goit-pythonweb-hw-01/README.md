# Тема 1. Python Development. Домашнє завдання

У папці містяться рішення двох завдань з використанням типізації, абстракцій та логування на рівні `INFO`.

## Вміст

- `task1_factory.py` — реалізація патерна фабрика для створення транспортних засобів з регіональними специфікаціями `US Spec` та `EU Spec`.
- `task2_solid.py` — перероблена система керування бібліотекою книг відповідно до принципів `SOLID`.

## Особливості виконання

- замість `print` використано модуль `logging`;
- додано типізацію для класів, методів і змінних;
- використано абстрактні базові класи та інтерфейси;
- код підготовлено у форматі, сумісному з `black`.
